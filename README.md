### Висновки

Під час виконання домашнього завдання було реалізовано та порівняно три алгоритми сортування: сортування вставками (Insertion Sort), сортування злиттям (Merge Sort) та Timsort.

Сортування вставками показує прийнятну продуктивність на невеликих і майже відсортованих масивах, проте на великих невпорядкованих наборах даних його квадратична складність O(n²) призводить до значного збільшення часу виконання.

Сортування злиттям забезпечує стабільну асимптотичну складність O(n log n), тому значно краще масштабується зі збільшенням кількості елементів.

Timsort використовує переваги сортування вставками та злиттям, а також враховує вже відсортовані послідовності елементів. Завдяки цьому він ефективно обробляє різні типи даних.

Однак під час порівняння необхідно враховувати, що вбудоване сортування Python має оптимізовану реалізацію, тоді як два інші алгоритми реалізовані безпосередньо мовою Python. Тому різниця у швидкодії пояснюється не лише особливостями алгоритмів.

**Висновок:** для більшості практичних завдань доцільно використовувати вбудовані функції `sorted()` або `list.sort()`, оскільки вони забезпечують високу продуктивність, стабільне сортування та не потребують реалізації власного алгоритму.
